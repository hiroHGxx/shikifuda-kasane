0. 目的・範囲・前提

  • 対象ユーザー: リンクを踏んで初めて来た人。『月蝕綺譚』を知っている人が主だが、Stack式の遊びと本作の固有ルール（浄化・幅の回復・八十段・稽古・番付）は知らない。
  • 対象ジャーニー: 開く → 何のゲームか分かる → 入る（帳）→ とめる → 細る／浄化に気づく → 進みと交代を知る → 高みに届く → 終わる → 記録が残る → もう一度 → 音を止める → 順位を探す → 別の配布経路 → 稽古。
  • 対象外: 速度曲線・幅回復量のチューニング、番付の中身（枠の中でしか成立せず自動操作では見えない）、二次創作ガイドライン適合、PV・わいわい掲載ページ、見た目の金継ぎ（08-30 実施済み）。
  • 実施環境: このリポジトリを観察スクリプトが http://127.0.0.1:8972/ で配信したもの。本番 origin（github.io）では実施しない——枠の外では SDK が localStorage に落ちるので、本番の fudakasane_save（オーナーの最高段・称号）を書き換えてしまう。ローカル origin は同時に「初見の状態」でもある。
  • 受入の正本: docs/SPEC.md（節番号で追跡）。08-30〜31 の更新は §7-a／§7-b／§7-c、09-01 の安全余白は DEVELOPMENT.md 末尾。
  • 前回との比較: 本作は初回。ただし検品（08-30・DEVELOPMENT §12）で「記録が黙って潰れる」「上限超えの best が満月成就に化ける」の2件を直しているので、C-7／C-8 はその回帰確認を兼ねる。
実施順の逸脱について（明示）: 設定の execution.order は非破壊→可逆変更→不可逆の順だが、 本作は入口（A-2）を通らないと盤面に入れない単一の遊び体験であり、体験順に実施する。 可逆変更は localStorage の1キー（fudakasane_save の束）に限られ、UT用 origin ごと捨てられる。 不可逆・外部影響の操作は、枠の外で開く限り存在しない（submitScore は local:true で端末内に閉じる。 観察スクリプトは念のため sdk.js を遮断する）。自動プレイのハッシュは記録も番付も触らない（canSubmitScore()）。
