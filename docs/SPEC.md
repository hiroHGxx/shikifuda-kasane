# 式札かさね 仕様書

『月蝕綺譚 -Luna Occulta-』二次創作の積み上げパズル。御霊おとしに続く第2弾。
本書は 2026-08-21 時点の実装仕様。

## 1. ゲーム概要

- ジャンル: Stack式（積み上げ）パズル。等角投影（2.5D）
- プラットフォーム: モバイルブラウザ優先の Web（PC も可）
- 遊び方: 宵闇を往き来する式札をタップでとどめて重ねる。ずれた分は夜に喰われて札が細り、空振りで夜明け（ゲームオーバー）
- 世界観: 月が蝕まれる夜、あるじどのが式札を重ねて「喰われた月への道を架ける」。第一夜の召喚描写（月へ呼びかける）に接続
- ビジュアル: 公式トンマナ「宵闇に金」（御霊おとしと共通トークン）

## 2. 盤面・物理

- 論理座標 480×720。等角投影 ISO_X=0.86 / ISO_Y=0.5、CX=240、BASE_Y=560
- 札: footprint F0=190（正方形）、厚み TH=30
- 交互に X軸・Z軸方向へスライド（本家準拠）。速度 `min(170 + 段*4.2, 460)`
- ぴったり判定 PERFECT_TOL=7px。**5連続以上のぴったりで幅が+6px回復**（本家準拠・入れすぎ注意）
- ずれ: 欠けた分は破片として落下（絵柄も一緒に欠ける）
- カメラ: `floors*TH - 300` を追従（lerp 6/秒）

## 3. 御霊の階梯（段位）

8段ごとに交代。**最初は明るい餡音**（眠たげなネムでは開幕が締まらないため）。

| 段 | 御霊 | 五行色 |
|---|---|---|
| 1–8 | 餡音 | 木緑 #6FB069 |
| 9–16 | 於兎 | 土琥珀 #C08A3E |
| 17–24 | ネム | 水青 #5FB4D9 |
| 25–32 | ネコマタ | 金白金 #C6BFA8 |
| 33–40 | 弁天 | 水青 #5FB4D9 |
| 41–48 | 宇迦 | 火紅 #E0562F |
| 49–56 | イズナ | 金白金 #C6BFA8 |
| 57–64 | 紫苑 | 木緑 #6FB069 |
| 65–71 | 咲耶 | 火紅 #E0562F |
| 72– | **栞**（MOON_ZONE） | 金泥 #F0CE7E |

- 札の天面にその御霊の札絵を敷く（上2枚のみ描画。顔が中央上寄りに来るよう上端の正方形を使用）
- 72段からは金縁の「栞の段」。鈴が約2.6秒おきに鳴る
- **80段（MOON_FLOOR）で満月成就＝クリア**。ここで一夜は終わる（札は出ず、入力も止まる）
  - 咲耶のカットイン → 栞の満願台詞 → 4.6秒後にクリア画面
  - クリア画面は夜明けと同じ `#overlay` を出し分ける。`#result-card.clear` で金泥の縁・栞の札絵・満願の言葉を出す

## 4. 演出

- **帳（とばり）**: 開始時、黒緞子の扉が閉じた状態で現れ → 栞の台詞 → 拍子木とともに左右へ開く（1.5s）。合わせ目の金襴帯は自作SVG（花紋＋蔓唐草の繰り返し。公式素材は不使用）
- 背景: 夜空グラデ＋星（固定位置・瞬き）＋昇る金の塵＋ビネット
- 月: 最高到達段に応じて満ちる（80段で満月）。満月成就後は脈動
- ぴったり: 金の粒バースト＋天面の環＋「浄化 ×n」
- 夜明け（空振り）: 結果画面は蝕紅の見出し＋到達した御霊の札絵
- 称号: 到達段で11種（宵の口→…→月白の頂→満月成就）。80段が上限なのでそれ以上の称号は置かない。最高記録は localStorage 永続

## 5. 音

- BGM: 公式配布キャラソング「Freehand」（ネムのテーマ）。音量0.16・ループ
- 琴: 御霊おとしと共通の実サンプル（G3 196.5Hz を変速で陰旋法に展開）。**ぴったり浄化は琴の音のみ**
- 拍子木・鈴・削げ音: WebAudio 合成
- **台詞（12場面）**: 帳が開くとき（栞）／各御霊の登場時（8段ごと）／72段（栞）／満願（栞）
  - 詳細は `docs/VOICE.md`

## 6. 稽古モード（裏モード）

- タイトルの「式札かさね」を**1.5秒以内に3回タップ**で起動。「稽古（札が欠けない）」と表示
- 札が細らず、空振りしてもゲームオーバーにならない。80段までの演出・台詞を通しで確認するため
- **実装上の注意**: `click` ではなく `pointerdown` で数える。iOSのダブルタップズーム抑止（touchend の preventDefault）が2回目以降の click を打ち消すため
- `#autotest`（自動でぴったり）、`#autocut`（わざと40pxずらす）もデバッグ用に残置

## 7. 入力・iOS対策

- pointerdown で札を置く。開始・リトライ直後は700ms入力を受けない（ボタンのタップの名残で即ミスするのを防ぐ）
- ダブルタップズーム抑止（350ms以内の2回目を preventDefault・ボタン除外）、`gesturestart` を preventDefault

## 8. アセットとビルド

- 札絵: 御霊おとしから流用（公式素材蔵ランク10）。**栞のみ公式正典シートを参照にLovartで生成**（`fuda_shiori.jpg`）
- ビルド: `node scripts/build-dist.js` → index.html（Pages用・単一ファイル）／ dist/artifact.html（全埋め込み・約13.5MB）
- **重要**: Artifact の CSP は `fetch(data:)` をブロックする。音源は `atob()` で直接 ArrayBuffer 化して decodeAudioData すること（fetch を使うと Artifact 上で全滅する）

## 9. 検証

80段までの通し確認は、実時間で自動プレイさせて撮るのが確実。

```bash
python3 -m http.server 8765          # リポジトリ直下で
node shoot.js out.png                # puppeteer-core で #autotest を開き overlay.show を待つ
```

- `#autotest` は「ぴったりの位置に来たら置く」ので**80段到達まで実時間で約77秒**かかる
- **Chrome の `--virtual-time-budget` では進まない**（rAF 駆動のゲームループが仮想時間で回らず、0段のまま撮れてしまう）。puppeteer で実時間待ちにすること
- 夜明け側の確認は `#autocut`（わざと40pxずらすので数段で終わる）
